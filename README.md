# 条文討伐

悪事をはたらく魔物を、正しい条文で斬る。本物の法律で戦う1日3体のバトル。

- 遊ぶ: https://satou-aaaaa.github.io/jobun-tobatsu/
- 魔物の悪事（事件）を読み、当てはまる条文のカードを選んで斬ります。当たれば魔物の体力が減り、外れると反撃で盾が減ります。3回斬れば討伐、盾が尽きると逃げられます。
- 魔物は12体（刑法・民法・憲法・労働基準法・特定商取引法・消費者契約法）。1体が1つの分野で、カードにはまぎらわしい条文が並びます。
- 今日の3体はだれでも同じで1日1回。上級（無法大君・体力5・カード4枚・ヒントなし）、練習、外した条文の「おさらい」、魔物図鑑、条文帳、実績（13個）、遊んだ日のカレンダー（取りこぼした日は7日以内ならあとから遊べます）。時間制限はありません。
- 条文は [e-Gov 法令検索](https://laws.e-gov.go.jp/) の本文から一部を写しています（2026年11月5日時点）。遊びのための例で、法律相談ではありません。
- 記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、まだ端末に保存が無ければ Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（条文と魔物の名前は入りません）。

## 開発

```bash
bash scripts/setup.sh          # 最初に一度
node qa/run.mjs                # 検査（CI と同じ）
python3 tools/check-laws.py    # 条文が e-Gov の本文と同じか（ネットが要る。条文を足した・直したとき）
```
